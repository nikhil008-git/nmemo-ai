# Site detail (`/sites/[id]`) — planned

## Purpose

Single-site command center for one customer website.

## Audience

Logged-in owner of that site.

## Layout (planned)

- Breadcrumb: Sites → {domain}
- Header: domain, status badge, re-sync button
- Tab nav or cards linking to sub-pages:
  - Overview
  - Conversations
  - Analytics
  - Knowledge
  - Embed
  - Settings (brand, rules)

## Overview widgets

- Messages last 7 days (sparkline)
- Leads / tickets created
- Top 5 questions
- Knowledge gaps count
- Embed snippet preview

## Actions

- Re-index site
- Open live widget preview
- Copy public site key
