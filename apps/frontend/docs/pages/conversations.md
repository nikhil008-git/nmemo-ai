# Conversations (`/sites/[id]/conversations`) — planned

## Purpose

Browse and inspect every visitor chat on a site.

## Audience

Site owner reviewing support/sales conversations.

## Layout (planned)

- Filter bar: date range, has lead, low confidence, page URL
- List: visitor id (masked), started at, last message preview, message count
- Click row → conversation detail drawer or page

## Conversation detail

- Full message thread (user / assistant)
- Citations used per assistant turn
- Tools called (create_lead, etc.) with results
- Visitor context: landing page, referrer, device
- Link to visitor memory summary if returning user

## Use cases

- QA: “Did the agent answer correctly?”
- Sales: follow up on leads
- Product: mine questions for FAQ gaps
